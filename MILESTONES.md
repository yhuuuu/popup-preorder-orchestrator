# Milestones

## M1 — Project Setup (Week 1)

**Due:** End of Week 1  
**Done when:**

1. Node.js + TypeScript project initializes successfully.
2. Health endpoint and auth middleware are working.
3. Base README and folder structure are committed.

## M2 — Orders API (Week 2)

**Due:** End of Week 2  
**Done when:**

1. `POST /api/orders` works with validation.
2. `GET /api/orders` supports pagination.
3. `PATCH /api/orders/:id/status` handles status transitions.
4. 400/401/404 cases are testable in Postman.

## M3 — Batch + Webhook (Week 3)

**Due:** End of Week 3  
**Done when:**

1. `POST /api/batches/generate` creates production summary.
2. Webhook callback can be sent to webhook.site.
3. Retry logic (max 3 attempts) is implemented.
4. Webhook attempt logs are saved.

## M4 — Showcase Pack (Week 4)

**Due:** End of Week 4  
**Done when:**

1. Postman collection is complete and exportable.
2. Integration diagram is finalized.
3. Common errors and fixes note is complete.
4. Demo-ready README is complete.
